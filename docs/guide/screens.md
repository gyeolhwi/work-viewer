# 화면 구성과 용어

읽기 전용이다. 뷰어에서 파일을 고치거나 에이전트에게 지시하지 않는다.

## 화면 용어

대화나 이슈에서 화면을 가리킬 때 쓰는 이름이다.

| 이름 | 무엇 |
|---|---|
| 요약 | 홈 맨 위의 타일들. 프로젝트별로 최근에 한 일 |
| 현황 | 요약 아래, 현황 카드들이 놓인 섹션 |
| 현황 카드 | 홈에서 프로젝트 하나를 담은 상자. 머리 아이콘의 둘레 고리는 에이전트 한 명당 한 칸이고, 칸 색은 작업 줄의 점과 같다 |
| 작업 줄 | 현황 카드 안의 에이전트 한 줄. 굵은 글씨는 마지막으로 보낸 지시이고, 누르면 펼쳐진다 |
| 파일 줄 | 현황 카드 맨 아래 오늘 바뀐 파일 |
| 기록 | 홈 아래의 지난 기록 |
| 사이드바 · 앱바 | 왼쪽 메뉴 · 좁은 화면(아이패드 미니 세로·폰)에서 아래에 붙는 메뉴 |

## 홈

- **요약**: 프로젝트마다 타일 하나. 가장 최근에 일한 날의 커밋 제목과 끝난 에이전트 작업을 세 줄까지 체크 표시로 보여 준다. 커밋이 없으면 많이 바뀐 폴더를 적는다. 오늘 일하지 않은 프로젝트는 체크 원이 흐리다.
- **현황**: 에이전트가 있는 프로젝트마다 현황 카드 하나. 확인을 기다리는 에이전트, 일하는 에이전트 순으로 위에 놓인다. 파일만 바뀐 프로젝트는 아래에 한 줄씩.
- 작업 줄의 점 색: 주황 확인 기다림, 파랑 일하는 중, 초록 끝남, 회색 대기.
- Claude Code 에이전트는 대화 기록에서 **내 지시 · 지금 하는 일(경과 시간·할 일 진행률) · 결과**를 뽑아 보여 준다. 질문이나 실행 승인을 기다리면 그 내용이 강조된다. Codex는 상태만 보인다.
- **기록**: 어제 이전의 변경을 날짜별로. 같은 프로젝트에서 30분 안에 이어진 변경은 한 묶음이다.

## 다른 탭

- **파일**: 작업공간 최상위부터 폴더를 열어 가며 탐색. Markdown·코드·이미지·PDF·영상 미리보기. 보고 있는 파일이 바뀌면 다시 불러온다. `INDEX.md`는 문서 목록 화면으로 보여 준다.
- **바뀐 파일**: 파일 추가·수정·삭제를 실시간으로. 프로젝트 칩으로 거른다.
- **Git**: 프로젝트를 골라 모든 브랜치의 커밋 그래프. 갈라지고 merge되는 선, 브랜치·원격·태그 이름표(파란 이름표는 지금 브랜치, ↑는 아직 푸시 안 한 브랜치), 속 빈 점은 merge 커밋. 지금 브랜치·커밋 안 한 변경·푸시 안 함·워크트리 수도 함께. 150개씩 더 불러온다.
- **문서**: 루트와 각 프로젝트 `INDEX.md`의 문서를 제목·요약·검색어로 찾는다.

## 화면 크기

- 860px 이하(아이패드 미니 세로·폰)는 왼쪽 사이드바 대신 아래 앱바를 쓴다.
- 내용은 최대 980px 한 줄로 놓는다. 넓은 화면에서도 두 줄로 나누지 않는다.
- 라이트·다크 모드는 기기 설정을 따른다.
